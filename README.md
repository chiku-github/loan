## 📌 Project Overview

The **Bank Loan Analysis Report** is an **Advanced Excel–based analytics project** designed to analyze loan applications, funded amounts, interest rates, and loan performance.  
This project helps financial institutions understand **loan quality, risk, and repayment behavior** through interactive dashboards.

---

## 🎯 Objective

- Analyze total loan applications and funded amounts  
- Track good vs bad loan performance  
- Monitor interest rates and debt-to-income (DTI) ratios  
- Understand loan distribution by purpose, term, and region  
- Support risk-aware lending decisions  

---

## 📝 Problem Statement

Banks handle thousands of loan applications annually.  
Without structured analysis, it becomes difficult to:
- Identify high-risk loans  
- Track repayment performance  
- Analyze customer loan behavior  
- Monitor profitability and risk exposure  

This project addresses these challenges using **Advanced Excel analytics**.

---

## 📊 Key Insights & Analysis

### 🔹 Loan Performance Overview
- Total Loan Applications  
- Total Funded Amount  
- Total Amount Received  
- Average Interest Rate  
- Average DTI Ratio  

### 🔹 Risk & Quality Analysis
- Good Loans vs Bad Loans  
- Fully Paid, Charged Off & Current Loans  
- Loan performance percentages  

### 🔹 Customer & Purpose Analysis
- Loan distribution by purpose (car, credit card, home improvement, etc.)  
- Loan term analysis (36 months vs 60 months)  
- Home ownership-based loan analysis  

### 🔹 Regional Analysis
- State-wise loan applications  
- Geographic loan distribution
